# عالم المودات — موقع لمشاركة مودات ماين كرافت

موقع ثابت (HTML/CSS/JS) بتصميم ماين كرافت لمشاركة **المودات، التكسترات، الخرائط والعوالم** مع الجميع، ويُنشر مجاناً على GitHub Pages.

## المميزات
- تصميم عربي (RTL) بستايل ماين كرافت مع غيوم متحركة وأرض عشب.
- تبويبات حسب النوع: مودات / تكسترات / خرائط / عوالم.
- بحث فوري، وفلترة حسب إصدار ماين كرافت، وترتيب حسب الأحدث أو الاسم.
- صفحة تفاصيل لكل عمل (الإصدارات، الحجم، سجل التحديثات) مع رابط مباشر قابل للمشاركة مثل `#ruby-tools`.
- قسم "طريقة التثبيت" وقسم "من أنا".
- إضافة عمل جديد = تعديل ملف `mods.json` فقط، بدون برمجة.

## حدود رفع الملفات

| طريقة الرفع | أقصى حجم للملف الواحد | تنفع لملفات 26–40MB؟ |
|---|---|---|
| رفع من المتصفح داخل المستودع (مجلد `downloads/`) | 25MB | ❌ لا |
| رفع عن طريق git من الكمبيوتر | 100MB (بس يبطّئ الموقع ويكبر المستودع) | ⚠️ غير مستحسن |
| **GitHub Releases** ✅ | **2GB لكل ملف، وعدد الملفات غير محدود** | ✅ **هذي الطريقة المستحسنة** |

موقع GitHub Pages نفسه حده 1GB، لذلك خلِّ ملفات المودات في Releases وخلِّ المستودع للموقع بس.

### رفع مود على Releases (من المتصفح أو الجوال)
1. افتح المستودع على GitHub ← **Releases** ← **Draft a new release**.
2. في **Choose a tag** اكتب اسماً مثل `dragons-v1.0` واضغط **Create new tag**.
3. اكتب عنوان، واسحب ملفك (`.mcaddon` أو `.mcpack` أو `.jar` أو `.zip`) إلى خانة المرفقات.
4. اضغط **Publish release**.
5. اضغط بالزر اليمين على اسم الملف ← **نسخ الرابط**، والصقه في خانة `file` داخل `mods.json`.

الرابط يكون بهذا الشكل:
`https://github.com/osama64986-cloud/Tt/releases/download/<التاج>/<اسم-الملف>`

### البيهيفر باك والريسورس باك معاً (بيدروك)
اجمع الحزمتين في ملف واحد `.mcaddon` عشان يتثبت بضغطة واحدة:
1. اضغط كل حزمة على حدة بصيغة zip (من داخل مجلد الحزمة نفسه، بحيث يكون `manifest.json` في أول مستوى).
2. ضع ملفي الـ zip داخل ملف zip ثالث.
3. غيّر امتداد الملف الثالث من `.zip` إلى `.mcaddon`.

## كيف أضيف مود جديد؟
1. ارفع الملف على **Releases** كما في الأعلى (أو في مجلد `downloads/` إذا كان أصغر من 25MB).
2. (اختياري) حط صورة للعمل في مجلد `images/`.
3. أضف عنصراً جديداً داخل `mods` في ملف `mods.json`:

```json
{
  "id": "my-mod",
  "name": "اسم المود",
  "type": "mod",
  "description": "وصف قصير يظهر على البطاقة",
  "details": "وصف أطول يظهر في صفحة التفاصيل",
  "versions": ["1.21.1"],
  "loader": "Fabric",
  "image": "images/my-mod.png",
  "color": "#8e44ad",
  "file": "downloads/my-mod-1.0.jar",
  "size": "2 MB",
  "version": "1.0",
  "date": "2026-11-12",
  "tags": ["سحر", "أسلحة"],
  "changelog": ["1.0 — الإصدار الأول"]
}
```

| الحقل | الشرح |
|---|---|
| `id` | معرّف فريد بالإنجليزي بدون مسافات (يُستخدم في رابط المشاركة) |
| `type` | واحد من: `mod`, `texture`, `map`, `world` |
| `loader` | Fabric / Forge / NeoForge / Bedrock Add-on / Resource Pack / Map / World |
| `image` | مسار صورة أو رابط. إذا تركته فارغاً يظهر لون `color` مع أيقونة |
| `file` | مسار الملف في `downloads/` أو رابط خارجي (Releases، CurseForge، Modrinth...) |

> **ملاحظة:** الأمثلة الموجودة في `mods.json` تجريبية، احذفها وضع أعمالك الحقيقية.

## النشر على GitHub Pages
1. ادمج هذا الفرع في `main`.
2. في المستودع: **Settings ← Pages ← Source** واختر **GitHub Actions**.
3. ملف `.github/workflows/pages.yml` ينشر الموقع تلقائياً مع كل تحديث على `main`.
4. الرابط بيكون: `https://<اسم-حسابك>.github.io/<اسم-المستودع>/`

## التجربة محلياً
```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```
(لازم سيرفر محلي لأن الموقع يقرأ `mods.json`، فتح الملف مباشرة ما يشتغل.)
