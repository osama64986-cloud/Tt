# نبض — Nabd

حزمة موارد (Resource Pack) أصلية لماينكرافت Bedrock: بلوكات العالم العادي مرسومة من الصفر
بعمق ولمعان (Vibrant Visuals / PBR)، مع حركة أكثر حيوية للاعب.

An original Minecraft Bedrock resource pack: overworld blocks painted from
scratch with depth and shine (Vibrant Visuals / PBR) and livelier player motion.

## التثبيت — Install

1. نزّل `dist/Nabd.mcpack` وافتحه — ماينكرافت يستورده تلقائياً.
2. الإعدادات ← الموارد العامة ← فعّل **نبض**.
3. للعمق واللمعان: الإعدادات ← الفيديو ← وضع الرسوم ← **Vibrant Visuals**
   (يحتاج إصدار 1.21.120 أو أحدث وجهازاً يدعمه؛ بدونه تظهر التكسترات الجديدة فقط).

## الرؤية بالليل — Night sight

ثبّت `dist/Nabd.mcaddon` (يحتوي الحزمتين). في إعدادات العالم فعّل:
- **حزم الموارد:** نبض (وضعه في أعلى القائمة فوق أي إضافة أخرى).
- **حزم السلوك:** نبض - الرؤية الليلية.

تضع ضوءاً خفياً حول اللاعب يلحق به، فترى بالليل وتحت الأرض بأي وضع رسم، والسماء تبقى بلونها.
ملاحظة: تفعيل أي حزمة سلوك في العالم يوقف الإنجازات (Achievements) فيه.

## اختيار الأيتمات — Choosing the item style

من الإعدادات ← الموارد العامة ← اضغط على علامة الترس بجانب **نبض**، واختر:
- **Nabd items / أيتمات نبض**: أيتماتنا المرسومة.
- **Game items / أيتمات اللعبة**: أيتمات اللعبة الأصلية كما هي، مع بقاء بلوكات نبض.

## كيف صُنعت — How it is made

كل التكسترات **مرسومة بالكود** في `tools/nabd/` (ضجيج، خلايا، طوب، ألياف خشب…)؛ لا توجد
صورة منسوخة من أي حزمة أخرى. الألوان فقط مضبوطة لتطابق ألوان اللعبة حتى تبقى البلوكات
معروفة ويعمل تلوين البيومات.

Every texture is generated by code in `tools/nabd/`; nothing is copied from
any other pack. Only colour references (so blocks stay recognisable and biome
tinting keeps working) come from Mojang's public creator samples.

```bash
python3 tools/make_world.py <vanilla resource_pack>   # haze + vivid biome colours -> pack_src (already committed)
python3 tools/make_animations.py     # player animations -> pack_src/animations
python3 tools/check_animations.py    # numeric sanity check of every expression
python3 tools/build.py --preview     # pack/ , dist/Nabd.mcpack , preview/*.png
```

- `pack_src/` — ملفات مكتوبة يدوياً (manifest، الأنيميشن، النصوص)
- `pack/` — الحزمة الجاهزة (تُولَّد)
- `preview/` — صور معاينة لكل التكسترات
