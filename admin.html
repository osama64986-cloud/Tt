🔐 دخول صاحب الموقع

هذي الصفحة لك أنت بس. الدخول يكون بمفتاح من GitHub، وبدونه ما أحد يقدر يغيّر شي حتى لو فتح الصفحة.

كيف أسوي المفتاح؟ (مرة وحدة بس)
  1. افتح صفحة إنشاء مفتاح جديد في GitHub.
  2. Token name: اكتب مثلاً admin-site، وExpiration: اختر 90 يوم.
  3. Repository access: اختر Only select repositories وحدد مستودع الموقع بس.
  4. Permissions → Repository permissions:
    • Contents: Read and write
    • Actions: Read and write
  5. اضغط Generate token وانسخه والصقه هنا.

⚠️ لا تعطي المفتاح لأي أحد ولا تنشره. إذا تسرب، احذفه من نفس الصفحة في GitHub وسوّ واحد جديد.
